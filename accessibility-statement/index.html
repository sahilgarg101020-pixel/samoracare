Accessibility Statement

Accessibility Statement

Nclude, Inc. is committed to making this website usable and accessible for people with disabilities.

Effective date

July 9, 2026

Our commitment

This website is operated by Nclude, Inc., a Delaware nonprofit corporation. We aim to provide a website experience that is clear, navigable, and usable with assistive technologies.

Accessibility standard

We aim to align this website with the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA where reasonably achievable.

Measures we support

Our accessibility efforts include readable layouts, sufficient color contrast, keyboard-friendly navigation, descriptive form labels, meaningful link text, and semantic page structure.

Feedback and assistance

If you experience difficulty using this website or need information in another format, please contact us through the contact method available on this website. Please include the page URL, a description of the issue, and the assistive technology or browser you are using if relevant.

Ongoing improvement

Accessibility is an ongoing effort. We review feedback and make updates as the website changes.
